Harvest Grocery App

Harvest is a full-stack grocery delivery system equipped with dual interfaces for customer ordering and stock management. Built to explore modern relational data workflows and responsive React routes.

Architecture & Details

Overview & Key Features

Designed to manage real-time inventory updates and customer checkout flows efficiently.

  • Back-end Architecture: Express + Node.js REST API layer
  • Database Storage: PostgreSQL database hosted on Supabase
  • Client Routing: Dynamic React routes for customer & manager portals
  • Authentication: Role-based access for stock management

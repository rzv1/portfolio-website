VaultGuard Security App

VaultGuard is a high-security cryptographic vault application built with layered Java architecture, hardware key validation, encrypted SQLite storage, and real-time audit logging.

Architecture & Security Details

Overview & Key Highlights

Engineered for zero-knowledge data isolation, hardware key verification, and encrypted secret storage.

  • Cryptography Engine: AES-256 GCM cipher pipeline & Key Derivation (PBKDF2)
  • UI Layer: JavaFX desktop environment with hardware unlock prompts
  • Logging Audit: Encrypted Log4j2 file appenders for authentication tracking
  • Data Storage: Embedded SQLCipher encrypted relational database
